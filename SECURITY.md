# Security Policy

## Supported versions

Scarce is in alpha. Only the latest release receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Report privately through GitHub:
**Security tab > Report a vulnerability** on
<https://github.com/NK2PSYCHO/scarce>.

Include the affected version, steps to reproduce, and the impact. You can
expect an acknowledgement within a few days. Fixes are released as soon as
practical and credited in the changelog unless you prefer otherwise.

## Scope notes

Scarce stores cairns (including copied code snippets) as plain text in the
extension's local storage and makes no network requests. Do not store secrets
in cairn comments or snippets.
